直面する危機に呆然自失となったダナオイ族の指導者たちは、食事や身体の手入れをおろそかにし、自らの過酷な運命を嘆く。ネストルに促され、彼らはアキッレウスのもとへ使節を派遣し、彼らの手助けとなるよう、彼の右手（友情の誓いと戦いにおける武勇）に懇請する。「テティスの子なる英雄」と呼ばれるアキッレウスは、彼らの祈りにも王の贈り物のいずれにも耳を貸さない。彼の情熱の相手であったブリーセーイスが、その身体に触れられることなく返還されたことでさえ、彼の心を動かすことはできない。王の名はこの箇所では挙げられていないがアガメムノンであり、使節たちも同様に名前が挙げられていない。ギリシア軍はダナオイ族やペラスゴイ族と呼ばれる。本巻は、使節たちがアキッレウスの不毛な返答を持ち帰り、その後ギリシア軍が食事と心地よい眠りで気力を回復させるところで終わる。アキッレウスは依然として彼らを助けようとしない。
