直面する危機に呆然自失となったダナオイの指導者たちは、食事や身体の手入れをおろそかにし、自らの運命を嘆く。ネストルに促され、彼らはアキレウスのもとへ使節を派遣し、彼らの手助けとなるよう、彼の右手（友情の誓いと戦いにおける武勇）に懇請する。「テティスの子なる英雄」と呼ばれるアキレウスは、彼らの祈りにも王の贈り物のいずれにも耳を貸さない。彼の炎であるブリセイスが、その身体に触れられずに返還されるとしても、彼の心を動かすことはできない。王の名はこの箇所では挙げられていないがアガメムノンであり、使節たちも同様に名前が挙げられていない。ギリシア軍はダナオイやペラスゴイと呼ばれる。本巻は、使節たちがアキレウスの不毛な返答を持ち帰り、その後ギリシア軍が食事と心地よい眠りで気力を回復させるところで終わる。アキレウスは依然として彼らを助けようとしない。
