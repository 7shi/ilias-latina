ヘクトルの最も忠実な妻アンドロマケは、幼い息子アステュアナクスを抱きながら、彼と言葉を交わそうとする。子供は父の兜と揺れる兜飾りに怯えて身を引くため、ヘクトルは青銅の兜を脱ぎ、息子を抱きしめ、息子が幼少期から父の徳に倣うことができるよう「最善の父」に祈る。その後ヘクトルはパリスを伴い、トロイアの城門を抜けて戦場へと戻り、ギリシア軍の指導者たちに挑戦する。

名乗り出るギリシア勢は、「計略の考案者」ウリクセス、猛々しいイドメネウス、父の血統ゆえに名高いメリオネス、ギリシア勢の勇壮な指導者アトリデス、二人のアイアス、輝く武具をまとい華麗なエウリュピュロス、偉大なアンドライモンの子トアス、そしてここでは名指しされない、ウェヌスの手を傷つけた戦士である。「トロイア勢の恐怖」アキレウスは不在であり、甘美な竪琴をもって自らの苛烈な愛を慰めている。王アトリデスの金箔を施した兜の中で籤が引かれ、ヘクトルと戦うために強大なアイアスが名乗りを上げる。このアイアスはテラモンのアイアス、テラモンの子、アエアキデスとも呼ばれ、ヘクトルはプリアミデスと呼ばれ、強大、戦に名高い、あるいは戦において最も偉大であると繰り返し描写される。

ヘクトルとアイアスは槍を投げ合い、次いで凄まじい叫び声の中で剣と盾をもって戦う。彼らの獰猛さは怒り狂った野猪に例えられる。アイアスはヘクトルの剥き出しの首を狙い、ヘクトルは身をかがめて盾で刃を払うものの、剣は彼の首をかすめる。次いでヘクトルは大石を投げつけるが、アイアスは七重の盾でこれに耐え、同じ石をもってヘクトルを打ち倒す。ギリシア勢に敵対するアポロがヘクトルを受け止め、彼を立たせて勇気を回復させる。彼らが再び剣を抜き放っていたとき、疲れたティタンが燃える戦車を波間に沈め始め、夜が空へと昇り、戦う両者を分かつために使者が送られる。

ヘクトルはアイアスの力に明白な高貴さを称賛し、彼の故郷と両親について尋ねる。アイアスは母としてヘシオネの名を挙げ、父としてテラモンの名を挙げる。ヘシオネの名と不幸を想起し、ヘクトルは共通の血筋を宣言して戦いをやめることを提案する。彼は金で飾られた剣をアイアスに与え、返礼として彫刻された帯を受け取る。両軍は引き退き、食事をとり、バックスの葡萄酒を飲み、眠りにつく。

翌朝、アウロラが星々を散らすとき、プリュギア人（すなわちトロイア勢）が集結する。前日の損失を想起し、ヘクトルはメネラオスの苛烈な炎を宥めるための略奪品とともに、無敗のアカイア人にヘレネを返還するよう促し、全員が承認する。イダイオスがその提案を猛々しいアトリデスの下へと携えていくが、アトリデスは耳を貸すことも略奪品を受け取ることも拒絶し、彼に陣営から立ち去るよう命じる。イダイオスは軽蔑され、トロイアの陣営へと戻る。ギリシア人はアカイア人やダナオイとも呼ばれる。この巻は、悲嘆に暮れるダナオイが戦死者たちを集めて巨大な積み薪の上で火葬し、次いで塹壕を修復して塁壁を樫の柵で囲むことで終わる。
