疲弊したギリシア勢が自らの陣営へと退却し、その防壁を巨大な閂で四方から固めるなか、トロイア勢は前進を続ける。好戦的なヘクトルは岩をもって陣門を打ち破り、鉄で補強された木組みを緩める。トロイア勢は門口から乱入し、敷居で抵抗するギリシア兵を討ち倒し、防壁から防衛者たちを駆逐する。成功が彼らに新たな力を与え、他の者たちは梯子を求め、燃える燃えさしを投げつける。ギリシア勢は壁や塔の上から戦い、石が飛び交う一方で、トロイア勢は楯の亀甲陣の下で迫り、進入路をよじ登り、陣門に押し寄せる。ついに恐慌がギリシア勢全員を捉え、彼らは陣営から逃亡して船団へと乗り込む。

「好戦的な」と呼ばれるヘクトルが、名指しされている唯一の個人である。トロイア勢はトロイア人、プリュギア人、そして末尾では「トロイアの若者たち」と呼ばれ、ギリシア勢はペラスゴイ、ギリシア人、ダナオイと呼ばれる。本巻は、ギリシア勢が船上にあり、叫び声が天空に響き渡るなか、トロイアの若者たちが飛び道具を次々と浴びせつつ攻撃を押し進めるところで締めくくられる。
