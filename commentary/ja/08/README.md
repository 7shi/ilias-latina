夜明け、ティタンが光線をもって世界を顕にするとき、ユピテルは神々を召集し、自らの言葉に反して武器をとって争ってはならないと警告する。次いで彼は木陰の多いイダ山へと降下し、イリオンの戦列を見守る。黄金の天秤を掲げ、彼はプリュギア人（すなわちトロイア勢）とアカイア人の運命を量る。ギリシア勢の破滅が重い武具とともに沈み、彼らの敗北を告げる。

プリアミデス、「プリュギアの栄光」、「トロイアの英雄」と呼ばれるヘクトルは、計り知れない怒りをもってダナオイを追い立て、全軍をもって圧迫する。アカイア人は混乱に陥り、彼らのドリスの陣営は騒乱で鳴り響く。城壁の内側に閉じ込められたアトリデス（アガメムノン）は、戦友たちを鼓舞し若者たちの士気を引き締める。燃えるような武具をまとって輝くテュディデス（ディオメデス）は、敵陣を突進し、巨大な武器を振りかざして立ち向かってくるアゲラオスを討ち取る。アイアスの巨大な武具に庇護されたテウクロスは、プリュギア人を追い立て、彼らの背中へと矢を放つ。彼は猛々しいゴルギュティオンを討ち、次いで誇り高きヘクトルの御者を討つ。ヘクトルは石をもってテウクロスの機先を制し、彼の弓を弾き飛ばして打ち倒す。テウクロスの忠実な仲間たちが殺戮の中から彼を救い出し、抱き起こす。

ヘクトルはあらゆる方向へ狂乱して突進し、槍をもって敵の隊列を恐れさせる。損失に動揺したダナオイは陣営へと逃げ戻り、樫の閂でその門を閉ざす。プリュギア人は塁壁に閉じ込められたギリシア勢を包囲し、歩哨をもって壁を取り囲み、篝火で包囲網を築く。この巻は、ギリシア勢が閉じ込められ、残りのトロイアの戦士たちが野原一面に横たわり、葡萄酒に耽りつつ憂いを解くことで終わる。

ギリシア人はアカイア人やダナオイとも呼ばれ、トロイア人はプリュギア人とも呼ばれる。
