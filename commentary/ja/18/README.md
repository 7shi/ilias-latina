その間に、ネストルの子である若きネストリデスと、その民の悲しむ若者たちが、アキレウスの親友パトロクロスの痛ましい遺体を陣営へと運ぶ。恐るべき凶報が、ペリデスおよびアエアキデスと呼ばれるアキレウスの耳を打つと、彼は青ざめ、熱気がその骨から去る。激しく涙を流しながら、彼は母から贈られた長衣でその手足を包み、爪で顔を掻きむしり、手入れの行き届いた髪を砂塵の中で汚し、強靭な胸から衣服を引き裂く。遺体の上に身を伏せ、彼は嘆きの声をあげて口づけをする。呻きと涙が止むと、彼は「向こう見ずな者」ヘクトルが親友を殺した償いをし、今歓喜しているまさにその武具の中で勝者として死ぬであろうと誓う。

激しい怒りに燃え、アキレウスは海へと駆け下り、嘆願者として母テティスに強固な武具を懇請する。波を離れた彼女は、ただちにウルカヌス（ムルキベル、イグニポテンスとも呼ばれる）の助力を請う。神は熱い炉の中でエトナの火を燃え立たせ、強烈な打撃で黄金を鍛え、やがて神的な技倆によって武具が完成する。テティスが飛び去り、偉大なるアキレウスはそれを身につけ、獰猛な視線を盾へと注ぐ。

残りの部分は盾の描写である。天の円蓋と星々、水のニュムペたちに冠された大地、周囲に配置されたネレウス、星々の巡り、夜の時、世界の四方位（アルクトスがアウステルから、日没が日の出からどれほど離れているか）、一つであるルキフェルとヘスペルス、そして三日月ルーナ。海の中には、強大なネレウス、老いたオケアヌス、決して同じ姿をとらないプロテウス、荒々しいトリトンたち、波を愛するドリスとネレイデスがいる。陸上には、森、恐ろしい野獣、河川、山々、そして城壁を巡らせた町々があり、そこでは争う民たちが双方に公平な裁判官の前で法を行使している。別の場所では純潔な乙女たちが歌いタンバリンに合わせて踊り、名のない奏者がリュラを奏で葦の笛で七つの調子を奏で、宇宙の運行に木霊する歌を響かせる。他の者たちは耕起し、刈り手が熟した穀物を刈り、葡萄栽培者が圧搾された葡萄に喜び、家畜の群れが草を食み、山羊が崖に佇む。本巻はこの描写の途中で締めくくられ、盾の中央に黄金のマルスが立ち、その周囲には破損した詩行ゆえに名が残されていない女神、そして蛇の髪を持つ嘆きのクロトとラケシスが立っている。アキレウスは武具を受け取り身につけたが、まだ戦闘には復帰していない。
