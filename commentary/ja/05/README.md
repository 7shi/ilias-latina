本巻はテュディデス、カリュドンの英雄または若者、そしてオエニデスと呼ばれるディオメデスの戦場での武勲を中心に据えている。マルスの激怒が増大する中でギリシア勢が退却するのを目にし、彼は最も激しい戦いの中へと飛び込む。戦好き、武装した処女、のちには聖なる戦乙女と描写されるパラスがその武具と腕力を補強し、勇気を与える。彼女の神聖な力に守られ、彼は牛を襲う飢えた牝獅子の如くトロイア勢を追い散らす。ギリシア人はダナオイやアカイア人とも呼ばれ、トロイア人はプリュギア人やテウクロイとも呼ばれる。

ディオメデスはダレスの息子たちペゲウスとイダイオスに対峙する。ペゲウスの槍は彼の防御を破ることに失敗し、ディオメデスは胸を貫く槍をもって彼を討ち果たす。イダイオスは兄弟の復讐を試みるがディオメデスに耐えきれず、雛鳥を殺す鷹の前に無力な鳥に喩えられながら、やがて退却して死を免れる。もう一人のアトリデスであるアガメムノンもトロイア勢に対して激怒し、オディオスを討ち取る。イドメネウスはマエオニデス・パイストスを襲い、その死に歓喜しつつ、ストロピオスの子を冥府の影たちのもとへと送り届ける。メリオネスはペレクロスを討ち、メゲスはペダイオスを討ち、エウリュピュロスはヒュプセノルを討ち倒してその武具を剥ぎ取る。

パンダロスは湾曲した角弓を手にディオメデスを捜し求め、矢をもってその肩をかすめる。制止されるどころか怒りを燃え立たせたディオメデスは獅子の如く突撃し、アステュノオス、力強きヒュペイロン、ポリュイドス、アバス、戦で名高いクサントス、巨躯のトオン、そして最後にクロミオスとエケムモンを討ち取る。次いで彼は顔と頭部への壊滅的な傷をもってパンダロスを討ち果たす。ディオメデスとアイネイアスは槍を交わし、互いに譲らず至近距離で激しく戦う。ディオメデスはついに十二人の若者でも動かすのがやっとである岩を持ち上げ、アイネイアスを叩き伏せる。

アイネイアスの母ウェヌスが降臨し、彼を抱き留めて黒い霧の中に隠す。ディオメデスはこの神の隠蔽をも突き抜けて追撃し、死すべき人間の槍をもって彼女の天の御手を傷つける。キュテレアとも呼ばれるウェヌスは天へと逃れ、天上の母に訴え出る。トロイアのアポロがアイネイアス（ダルダニアのアイネイアス、ウェヌスの最も美しき御子とも呼ばれる）を保護し、その戦意を回復させて再び戦いへと復帰させる。

広範な殺戮の只中で、アイネイアスはギリシア勢を激しく圧迫する。最も雄々しき男、プリュギア人の唯一の希望と呼ばれるヘクトルも同様に彼らを押し戻す。彼の強襲は、羊飼いや番犬をものともせず羊の群れを襲う飢えた狼に喩えられる。ギリシア軍の戦列が崩れるにつれて、トロイア勢は自信を得る。ダナオイの王アガメムノンは馬を駆って指揮官たちを鼓舞し、次いで猛々しきアトリデスとしてリビュアの獅子の如く突撃する。彼の模範はギリシア軍の勇気を回復させ、敗走を逆転させる。アトリデスは次いでアイネイアスを襲うが、その投げ槍は狙った標的を外れ、代わりに御者を討ち取る。アイネイアスは飛び降りてクレトンとオルシロコスを討ち取る。続く叙述は、メネラオスの手によるパフラゴニアの指導者の死と、アンティロコスの手によるミュドンの死を記録している。

ユピテルの名高い御子サルペドンが戦闘に加わり、偉大なるヘラクレスの子トレポレモスを討ち倒すが、父の力も難行もトレポレモスを救うことはできない。サルペドン自身も傷を負って退却する。謀略の考案者と呼ばれるウリクセスは、次いで七人の名もなき雄々しき若き戦士たちを討ち倒す。いまやマウォルスのヘクトル、祖国の支柱と呼ばれるヘクトルとディオメデスが相対する陣営で戦い、野を死体と血潮で覆い尽くす。

本巻は神々の戦いをもって幕を閉じる。マウォルスと呼ばれ、戦に強大なマルスが、巨大な盾を構えて貞淑なパラスに対峙する。パラス自身が彼を追い散らし、自らの槍で彼を傷つけ、天へと退却することを強いる。そこで彼は天の王であり偉大なる父であるユピテルに訴えるが、叱責を受ける。結びの情景はこうして、天において負傷した軍神が屈辱を味わう場面となり、地上における人間たちの戦いは決着がつかぬまま残されるのである。
