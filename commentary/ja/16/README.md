味方の殺戮にもはや耐えかねたパトロクロスは、突如としてアキレウスの武具で武装し、偽りの姿でトロイア勢を恐怖に陥れる。先ほどまでダナオイを混乱に陥れていた者たちが恐慌をきたして逃走し、彼は彼らに迫り、その戦列を乱して軍勢中で男たちを討ち倒す。彼は巨大な傷でサルペドンを討ち倒し、「恐るべきアキレウス」の姿の下で戦いを繰り広げる。

彼が同盟軍の諸部隊を殺戮によって混乱させているのを見て、熱情に燃えるヘクトルは勇気を奮い立たせ、巨大な武具に身を包んだ巨躯をもって彼を迎え撃つべく立ち向かう。彼は彼を「最も勇猛なアキレウス」と呼びかけて挑発し、復讐に燃えるトロイアの右手に何ができるか、そして「最も勇敢なヘクトル」が戦いにおいてどれほど強いかを思い知らせてやると豪語する。マルスとも呼ばれる軍神マウォルスが彼を保護しているとしても、この右手が彼を破滅させるであろうと。パトロクロスは沈黙を守り、真のアキレウスと見なされるように、その脅しを軽蔑して退ける。

ここでは「ダルダニデス」と呼ばれるヘクトルが、まず槍を投げる。パトロクロスは素早い一撃でそれを受け止め、今度はお返しとばかりに投げ返す。しかし彼の返礼の一撃は盾によって弾かれ、大地に落ちて止まる。それから彼らは剣を抜き、白兵戦を繰り広げるが、ついに「トロイアのアポロ」が偽りのアキレウスの素顔を暴き、彼の武具を剥ぎ取る。偽りの武具で戦う彼を捕らえた「戦いにおいて最も偉大な」ヘクトルが彼に襲いかかり、剣でその剥き出しの胸を貫く。本巻は、ヘクトルが勝利を収め、ウルカヌスの武具を剥ぎ取るところで締めくくられる。
