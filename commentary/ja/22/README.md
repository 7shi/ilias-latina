ヘクトルの両親はトロイアの城壁から、息子が死へと近づくのを見守り、みずからの破滅が息子の死と結びついているのを悟る。トリトニアおよびパラスと呼ばれるミネルウァは、彼の兄弟デイポボスの姿をとってヘクトルの前に現れる。兄弟が自分を守るためにそこにいると欺かれたヘクトルはアキレウスに立ち向かい、女神はその加護をギリシア勢へと戻す。二人の英雄は槍を投げ交わし、剣と盾をもって至近距離で激しく戦う。ヘクトルはアキレウスの槍を躱すが、彼自身の投げ槍はウルカヌスの武具に対して通じない。その切っ先は硬い黄金に当たって曲がり、砕け散る。二人は接近戦を再開するが、ヘクトルの体力は尽きかける。後退しながら兄弟の助けを求めるが誰も見当たらず、彼は欺かれていたことに気づく。疲弊し両目を闇に覆われながらも、彼は呻きを抑えつつ戦い続ける。アキレウスは彼を押し戻し、その喉の中央へと槍を突き刺す。ギリシア勢は歓喜し、トロイア勢は嘆き悲しむ。

死にゆくヘクトルは、悲嘆に暮れる両親のもとにみずからの遺体を返還するようアキレウスに請い、父プリアモスが惜しみない黄金でそれを買い戻すと約束する。彼はギリシアに恐れられた統治者としてのプリアモスの偉大さに訴え、とりわけ子を失った父親へのアキレウスの共感に訴える。アキレウスはプリアモスを想うときにみずからの父ペレウスを、ヘクトルを想うときにみずからの息子ピュロスを思い浮かべるべきである、と。アキレウスはこれを拒絶する。もし自然が許すならヘクトルを八つ裂きにして自ら喰らってやりたいと言い放ち、その遺体を野獣や鳥、犬どもの餌食として遺棄すると脅す。死者に感覚があるならば、このことがパトロクロスの亡霊に歓びをもたらすであろうと彼は言う。アキレウスが語っている最中にヘクトルは息を引き取る。それでも満ち足りないアキレウスは、死体をみずからの戦車に縛りつけ、トロイアの城壁の周囲を足を引いて3周引きずり回したのち、塵にまみれた遺体をギリシア軍陣へと連れ帰る。

ヘクトルは直接名指されるとともに、「プリアモスの息子なる英雄」、「プリアミデス」、「プリアモスの子」とも呼ばれる。彼は抜け目がなく、不運で、憐れむべき者として描かれる。ヘクトルの嘆願の中でプリアモスの名に続く「指揮官たちの指揮官（ギリシアがただひとり恐れた男）」という語句は、プレシスとフォルマーの双方がヘクトル自身を指すものと解釈している。彼の母の名は明かされない。アキレウスはアイアコスの子孫であることを示す「アエアキデス」、海の女神テティスを母に持つことを示す「ネレウスの英雄」と呼ばれ、また獰猛で、大いなる者、最大の英雄、頑なの者としても描かれる。ギリシア勢はダナオイと呼ばれる。デイポボスはパラスがその姿を模したヘクトルの兄弟であり、戦闘における実際の支援者ではない。ペレウスとピュロスはヘクトルの嘆願を通じてのみ登場し、亡きパトロクロスはアキレウスの復讐の説明を通じて現れる。

この巻は、ヘクトルの遺体がギリシア勢の手に渡ったところで幕を閉じる。ダナオイが祝う一方で、トロイア勢はヘクトルを悼み、その死を通じて、あたかもトロイアそのものがすでに陥落したかのように城壁を嘆き悲しむ。
