首領たちが争う中、オリュンポスの全能の支配者が神々の会議を開く。パンダロスはメネラオスを狙い撃つことで条約を破棄する。その矢は鉄の鱗片で強固なチュニックを貫通し彼を負傷させる。「アトリデス」と呼ばれるメネラオスは呻きながら陣営へと退き、そこで父の医術で訓練を受けた若きポダレイリオスがパイオニアの薬草で彼を治療する。その後彼は勝者として再び戦いの中へと向かう。アガメムノンの怒りが勇敢なペラスゴイ勢を武装させ、共通の悲痛が全軍を戦いへと駆り立てる。

戦闘は全面的なものとなり、トロイア勢とダナオス勢の双方に大きな損失が出る。軍神マウォルスが、飛び道具の雨の中でいたるところに鳴り響く。アンティロコスは剣でタリュシアデスを討ち取る。テラモンのアイアスは、ギリシア勢を圧迫していたアンテミオンの子をその胸を貫いて討ち倒す。次いでアンティポスがアエアキデス（ここでのアイアスの呼称）に向かって槍を投じるが狙いを外し、レウコスの鼠径部を突く。レウコスは草を噛みながら死にゆく。「倦むことなきアトリデス」は友の死に心を揺さぶられ、こめかみを貫く巨大な槍でデモコオンを討ち、次いで剣を抜く。彼の敵は仰向けに倒れる。一方、インブラソスの子ペイロオスは石でアマルンケスの子を討ち取っていた。ペイロオスが死んだ若者の武具を剥ぎ取ろうと準備する中、トアスがその肩と胸を貫いて槍を投じ、彼を自らの武具の上にうつ伏せに倒れさせ、血を流して身悶えさせる。

この巻は、血塗られたダルダニアの平原のいたるところでなおも戦闘が激しく荒れ狂う中で終わる。ギリシア勢はまたダナオス人、ペラスゴイ人、アカイア人とも呼ばれる。どちらの陣営も勝利を確定させてはいない。双方が打ち勝とうと奮闘を続ける中、今やトロイア勢に、今やアカイア勢に勇気が湧き上がっているのである。
