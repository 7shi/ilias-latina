首領たちが争う中、オリュンポスの全能の支配者が神々の会議を開く。パンダロスはメネラオスを狙い撃つことで条約を破棄する。その矢は鉄の小札で補強されたチュニックを貫通して彼を負傷させる。「アトリデス」と呼ばれるメネラオスは呻きながら陣営へと退き、そこで父の医術で訓練を受けた若きポダレイリオスがパイオンの薬草で彼を治療する。その後彼は勝者として再び戦いの中へと向かう。アガメムノンの怒りが勇敢なペラスゴイを武装させ、共通の悲痛が全軍を戦いへと駆り立てる。

戦闘は全面的なものとなり、トロイア勢とダナオイの双方に大きな損失が出る。軍神マウォルスが、飛び道具の雨の中でいたるところに鳴り響く。アンティロコスは剣でタリュシアデスを討ち取る。テラモンのアイアスは、ギリシア勢を圧迫していたアンテミオンの子をその胸を貫いて討ち倒す。次いでアンティポスがアエアキデス（ここでのアイアスの呼称）に向かって槍を投じるが狙いを外し、レウコスの鼠径部を突く。レウコスは草を噛みながら死にゆく。「倦むことなきアトリデス」は友の死に心を揺さぶられ、こめかみを貫く巨大な槍でデモコオンを討ち、次いで剣を抜く。彼の敵は仰向けに倒れる。一方、ペイロオス・インブラシデスは石でアマリュンキデスを討ち取っていた。ペイロオスが死んだ若者の武具を剥ぎ取ろうと準備する中、トアスが槍を投じてその肩と胸を貫き、彼を自らの武具の上にうつ伏せに倒れ込ませる。ペイロオスは血を流しながら身悶えして息絶える。

この巻は、血塗られたダルダニアの平原のいたるところでなおも戦闘が激しく荒れ狂う中で終わる。ギリシア勢はまたダナオイ、ペラスゴイ、アカイア人とも呼ばれる。どちらの陣営も勝利を確定させてはいない。双方が勝利を求めて奮闘を続ける中、ある時はトロイア勢に、ある時はアカイア人に勇気が湧き上がり、一進一退の攻防が続くのである。
