アイアスは偉大な力をもってアカマスを討つ。メネラオスは巨大なアドラストスを捕らえ、敵に対する勝利の歓喜を求めつつ、背後に両手を縛った彼を船団へと引き立てていく。ダナオイが前進する一方で、トロイアの若き戦士たちは無防備な背後を盾で覆いながら後退する。

マウォルスのヘクトルは、神々がダナオイのために戦っており、「武装した処女」であり「未婚のパラス」やミネルウァとも呼ばれる女神が自軍の男たちの力を奪っていることを認識する。彼は直ちに城壁へと向かい、ヘカベを呼び出すよう命じ、その女神を宥めるよう促す。イリオスの女たち（トロイアの女たち）はパラスの堅固な城塞へと登り、祝祭の花輪で祭壇を飾り、慣習に従って羊を生贄に捧げる。ミネルウァの神殿の嘆願者であるヘカベは、愛する子供たちと夫のために母の祈りを捧げる。

その間に、グラウコスは抜き身の鋼をもってディオメデスと戦う準備をする。ディオメデスは彼の名、血統、出身地を尋ねる。グラウコスが槍を投じようとする中、「アイトリアの英雄」と呼ばれるディオメデスは、より優れた武器に立ち向かう彼の無謀さに異議を唱える。彼はグラウコスが対峙している武具が、ウェヌスの右手を傷つけ、戦いでマルスを貫いた客友のものであると明かし、怒りと武器を抑えるよう彼に告げる。この巻は両者が対決を放棄して盾を交換することで終わり、ヘカベの祈りの結末は報告されない。
