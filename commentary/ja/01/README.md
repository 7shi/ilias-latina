本巻は、ギリシア人に悲惨な死をもたらし、英雄たちの魂をオルクスへと送り、その遺体を犬や鳥のために葬られぬまま放置した、傲慢なペリデスと呼ばれるアキレウスの怒りを歌うよう女神に呼びかけることで幕を開ける。これらの災禍は「至高の王」ユピテルの意志を果たすものであり、笏を執るアトリデス、アガメムノンと、戦で名高いアキレウスとの間の諍いから生じる。ギリシア人はダナオイ、アカイア人、そしてアルゴスの民とも呼ばれ、アガメムノンはペラスゴイの王とも呼ばれる。

直接の原因は、アガメムノンがクリュセイスをその父クリュセスに返すことを拒絶したことである。クリュセスは聖なる鉢巻きを締めたアポロの神官であり、その悲嘆、老齢、そして敬虔さによって繰り返し特徴づけられている。彼はギリシア軍の陣営を訪れ、アガメムノンの膝に取りすがり、贈り物を差し出し、自らの命の支えであると語る娘を懇願する。ミュルミドンは彼の涙に心動かされて彼女の返還を促すが、アガメムノンは娘への燃え盛る情熱のために神聖な義務を蔑ろにして彼を追い払う。アポロの神殿へと戻ったクリュセスは激しく嘆き、生涯にわたる崇拝がなぜ何の加護ももたらさなかったのかと問いかけて神に訴える。彼は、己の知らぬ過ちのために娘が苦しむくらいなら、自らを神の矢に差し出そうとする。アポロ（ポエブス、デルポイの神、予言の神、そしてラトナと偉大なるユピテルの子と呼ばれる）は、ギリシア人の間に壊滅的な疫病を送ることでこれに応じる。

九つの夜ののち、アキレウスは疫病の原因を突き止めるために第十の日にギリシア軍の長たちを召集する。テストリデスとも呼ばれる予言者カルカスは、原因と解決策の双方を知るが、アキレウスが身の安全を保証するまで口を開くことを恐れる。彼は、怒れるポエブスを鎮めるためには、貞淑なクリュセイスをその信心深き父のもとへと返さねばならないと宣言する。アガメムノンはカルカスを嘘つきと非難し、全体の騒然とした叫びの中でアキレウスと罵倒を交わす。ついに彼は屈服する。クリュセイスは多くの贈り物とともに、手つかずのまま返還される。「万人に知られた」ウリクセスが彼女を船で故郷の町へと連れて行き、ギリシア軍の艦隊へと船で戻る。アポロは鎮められ、ギリシア人はその力を取り戻す。

依然としてクリュセイスを失ったことを悲しむアガメムノンは、他人の愛する女によって己の情熱を慰めるため、アキレウスからブリセイスを強奪する。アキレウス（偉大なるアキレウス、不敗の指導者、猛々しいアエアキデス、そしてペリデスとも呼ばれる）は剣を抜き、名誉ある軍務の褒賞が返還されぬならば死を免れぬとアガメムノンを脅す。アガメムノンは自らを守る構えをとるが、貞淑なパラスがアキレウスを引き留め、流血と恥辱を防ぐ。アキレウスは次いで、アガメムノンをプリステニデスと呼びつつ、海に住まう母テティスに復讐を訴える。テティスは近くのミュルミドンの陣営へとやって来て、天へと昇る前に戦いから身を引くよう我が子に促す。

テティスは至高の父、至高の王、雷神、そしてオリュンポスの父であるユピテルに哀願し、我が子とその愛に対してなされた不名誉の復讐を果たしてくれるよう求める。ユピテルはその件を処理すると約束し、アキレウスを慰めるよう彼女に告げる。彼女は海へと戻る。ユノーは、ドリスの娘と彼女が呼ぶテティスとアキレウスが、ユピテルに自らの愛するギリシア人を滅ぼさせトロイア軍の力を奮い立たせさせるほどの影響力を持つべきではないと怒りのうちに抗議する。彼女はユピテルの妻および姉妹としての自らの立場を主張し、神々の夫妻は罵倒を交わす。名指しされない火の神が仲裁に入り、彼らの諍いをおさめる。ユピテルは集会を解散させる。本巻はオリュンポスでの日没で終わる。神々は豪勢な宴を楽しみ、それから自らの寝所へと引き取って眠りにつく。
