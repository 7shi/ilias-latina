この巻は、人間たちと神々が休息についている夜に幕を開ける。「全能の父」、また「雷神」とも呼ばれる神は、夜明けの攻撃を命じるためにソムヌスをアガメムノンの陣営へと遣わす。「神々の中で最も穏やかな神」にして「憂いと苦難を和らげる神」であるソムヌスは、眠る王のもとへと飛び立ち、太陽であるティタンが波間から昇ったなら、仲間たちを武装させてイリオスの平原へと進軍するように告げる。アガメムノンは「ダナオイの王」および「アトリデス」と呼びかけられ、語り手は彼を「ペロプス家の英雄」とも呼ぶ。その後、ソムヌスは天へと帰還する。

夜明けにアガメムノンは指導者たちを軍議に召集する。彼らは結束した武力を誓い、アガメムノンはその勇気に感謝する。トロイアで最も醜く、最も放漫な物言いをする男と描写されるテルシテスは、戦争の継続に反対を唱え、帰国を促す。「その献策で名高い」ウリクセスは彼を叱責し、象牙の笏で打ち据える。老齢から来る知恵を持つ機略縦横のネストルが穏やかに秩序を回復するまで、この争いは危うく武力による暴力へと発展しかける。彼はアウリスでの凶兆（大蛇が八羽の雛鳥とその後その母鳥を呑み込んだこと）を想起する。カルカスの予言を引き合いに出し、ネストルは、イリオンがギリシア軍の武器の前に陥落する十年目に、彼らの定められた戦いが成就を迎えると宣言する。集会は彼の助言を承認して解散する。アガメムノンは準備を命じ、次の夜明けに軍勢に武装して進撃するよう命じる。

詩人は指導者たち、その系譜、故郷、そして船団を詳述するためにムーサたちに祈願し、この事業を鼓舞し好意を示すようアポロに求める。ギリシア勢の目録は、ボイオティアの指導者たちであるペネレオス、レイトス、アルケシラオス、プロトエノル、クロニオスから始まる。ミュケナイに生まれ、「好戦的なギリシア」によって王に選ばれたアガメムノンは、百隻という最大の部隊を率いてくる。他の指導者には、熱烈なメネラオス、激しい激情を特徴とするアガペノル、そして二人の息子を伴い、鋭い精神と強力な献策力を持つ忠実なネストルが含まれる。スケディオスとエピストロポスは強く強大であり、「ミュルミドン人の栄光」、「獰猛な戦争の二つの防壁」と呼ばれる。ポリュポイテスとレオンテウスが続き、次いで戦いにおいて勇敢なエウリュアロス、ステネロス、テュディデス、強大なアスカラポスと勇敢なイアルメノス、ロクリス人の最も勇敢なアイアス（後に「オイレウスの子アイアス」と呼ばれる）、そしてエウアイモンの子が続く。

アキレウスは母の海を渡る「ギリシア人の防壁」である。目録はまた、テッサリアの若者ペイディッポスとアンティポス、テウクロス、ロドスのトレポレモス、そしてエウメロスの名を挙げる。他の指揮官には、マグネシア人でテントレドンの子プロトオス、エウボイアのエレペノル、勇気と武技において際立つドゥリキオンのメゲス、アンドライモンの子であるアイトリアのトアス、そしてウリクセスを指す機略に富む「イタケ人」がいる。テラモンの子であるサラミスのアイアスは、ロクリス人のアイアスと区別され、卓越した勇気を称えられる。グネウス、クレタ勢のイドメネウスとメリオネス、アテナイのアテネ人メネステウス、そしてエリス勢の指導者たちアムピマコス、タルピオス、ポリュクセノス、ディオレスも現れる。プロテシラオスと勇敢なポダルケスにポイアスの子が続き、最後にポダレイリオスとマカオンが続く。ギリシアの総船団数は千二百隻に十四隻足りない数、すなわち千百八十六隻と記される。

ギリシア勢が船を陸に引き揚げ平原を占拠すると、今や「サトゥルヌスの子」と呼ばれる神聖な父は、勇敢なペラスゴイが戦いへと向かってきていることを知らせるため、イリスをプリアモスのもとへと遣わす。「プリアミデス」と呼ばれるヘクトルは、父の命令を受けて直ちに武装し、開かれた城門を通ってトロイアの若者たちを率いて出る。彼の武具は詳細な描写を受ける。すなわち、黄金に輝く兜、胸当て、盾、槍、剣、そして光り輝く脛当てである。

パリスがそれに続き、容姿はより美しく、今や武技においても勇敢であるが、はっきりと「戦争の原因」、「祖国の破滅的な災厄」と呼ばれる。彼とともにデイポボス、ヘレノス、勇敢なポリテス、そして「ウェヌスの紛れもない子」である神聖なアイネイアスがやって来る。トロイアおよび同盟軍の指導者たちには、アンテノルの子らであるアルケロコスと猛々しいアカマス、リュカオンの高貴な子パンダロス、戦いにおいて勇敢なグラウコス、アムピオス、アドラストス、アシオス、ピュライオス、アムピマコス、ナステス、気宇壮大なオディオスと力強きエピストロポス、猛々しいエウペモスと年齢ゆえに名高いピュライクメス、メストレス、アンティポス、ヒッポトオス、アカマス、ペイロオス、アルシノオスの子らで壮年の男たちであるクロミオスとエンノモス、ポルキュスと力強きアスカニオス、ユピテルの輝かしい子サルペドン、そして名高い地に生まれたコロイボスが含まれる。

ギリシア勢は様々にダナオイ、アカイア人、アルゴス人、ペラスゴイと呼ばれ、トロイアはまたイリオンやペルガマとも呼ばれる。この巻は、いかなる戦闘も語られる前に、ヘクトルの軍勢が進軍しトロイア軍の目録が完結したところで終わる。その最後の述懐は、これら指導者たちによって守られた「ネプトゥヌスのトロイア」は、運命が妨げなかったならばダナオイの謀略に打ち勝っていたであろう、というものである。
