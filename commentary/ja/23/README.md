アエアキデス（「アイアコスの子孫」）および「勝者」と呼ばれるアキレウスは、悼まれた友パトロクロスを葬り、葬礼のための厳粛な行列を率いる。次いで彼はヘクトルの憐れむべき四肢を塚の周囲に引きずり回し、亡き友の灰のために葬礼競技会を布告する。

競走においては、テュディデス（「テュデウスの子」）と呼ばれるディオメデスが、「足の猛々しい」と形容されるメリオネスを破る。アイアスはレスリングで、その機知によって相手の力を打ち負かした「ラエルテスの子」と呼ばれるウリクセスに敗れる。エペイオスは革紐を巻いた拳闘ですべての挑戦者を圧倒し、ポリュポイテスは重い円盤投げの競技を制し、メリオネスは弓矢で勝利を収める。

この巻は競技会が終わり、群衆を伴ったアキレウスが自らの陣営へと戻るところで幕を閉じる。パトロクロスはその葬礼の栄誉を受け、一方ヘクトルの遺体は塚での辱めののち、依然としてアキレウスの手中にある。
