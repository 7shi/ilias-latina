獰猛なヘクトルは激しい心をもって至るところで荒れ狂うが、ついに強大なアイアスが巨大な石で彼を打ち、彼を押し戻し、全身を伸ばして倒れ伏させる。トロイアの一隊が駆け寄り、血の奔流を吐くその若者をクサントスの流れる水で洗う。彼らはその後戦闘へと復帰し、双方で甚大な殺戮が繰り広げられ、大地は血糊で流れる。ポリュダマスが強烈な一撃でプロトエノルを討ち、テラモンのアイアスは「アンテノリデス」（アンテノルの子）と呼ばれるアルケロコスを討ち、アカマスはボイオティア人プロマコスを討つ。その後アカマスは獰猛なペネレオスの右手によって討ち倒される。本巻は、プリアモスの若者たちが斃れるなか、継続する戦闘のただ中で締めくくられる。
