ギリシア軍とトロイア軍が戦闘の身構えを整えて立つ中、パリスは対峙する隊列の中にメネラオスを目にし、恐怖に駆られて退却する。ヘクトルは弟を祖国と一族の恥辱として叱責する。パリスはもてなしてくれた主人の妻を誘惑することは躊躇わなかったのに、その不正によって戦争をもたらした夫を今や恐れているというのである。ヘクトルはパリスの美しさ、競技における武勇、愛への耽溺を、軍神マルスが要求する勇気と対比させる。彼は両軍が無武装で見守る中でパリスとメネラオスが二人だけで戦うことを提案する。パリスは同意し、ヘレネが平和裏に勝者に属するのであれば、快楽よりも武勇の方が自分にとって重要であると主張する。ヘクトルはその提案をギリシア勢に伝え、プリアモスが召集され、生贄が捧げられ、条約が結ばれる。両軍は武器を置き、平原を開け放つ。

アレクサンドロス、プリアモスの子、ダルダニアの若者、プリュギアの略奪者とも呼ばれるパリスが、メネラオスに向かって進み出る。メネラオスは「アトレウスの子」を意味するアトリデスと呼ばれ、攻撃の前にユピテルに祈願する。彼らは打撃と槍投げを交わし、次いで配偶者をめぐって競い合う牡牛のように、剣と盾をもって至近距離で戦う。パリスの鎧がメネラオスの槍から彼を救う。メネラオスは奪われた妻を思い起こして攻撃を激しくするが、彼の剣はパリスの兜に当たって砕け散る。そこで彼はパリスの兜を掴み、彼を投げ倒す。パリスは引きずり去られて命を落とすところであったが、キュテレアとも呼ばれ、パリス自身の守護の女神と描写されるウェヌスが彼を霧の中に隠し、兜の留め具を緩める。メネラオスは空の兜をギリシア軍の首領たちの間に投げ入れ、攻撃を新たにするが、ウェヌスはパリスを豪奢に飾られた寝室へと運び去る。

ウェヌスは城壁からヘレネをパリスのもとへと連れてくる。ヘレネは敗れ去った愛人を叱責するものの、情愛を込めて語りかけ、メネラオスが彼を討ち果たして二人の愛を終わらせてしまうのではないかという恐怖を描写する。彼女はかつての夫に再び挑むことのないよう彼に警告する。パリスは自らの敗北を貞潔なパラス（ミネルウァ）の怒りのせいにし、ウェヌスの助けがあればいずれメネラオスに打ち勝つであろうと約束する。二人は抱擁し愛を交わす。ヘレネはまた白鳥の娘たるキュグネイスとも呼ばれる。結びの官能的な情景は、パリスを彼女の炎であるとともに、トロイアを滅ぼす炎でもあるものとしている。

ギリシア勢はまたダナオス人とも呼ばれ、トロイア勢はプリュギア人とも呼ばれる。この巻は、勝利を収めたメネラオスがトロイア勢の間でパリスを無駄に捜索するところで終わる。ここでは名指しされていない彼の兄アガメムノンはギリシア軍の軍勢を鼓舞し、敗北したトロイア勢を叱責して、条約の履行とヘレネの返還を要求する。その要求は結びにおいて未回答のまま残される。
