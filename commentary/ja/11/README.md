夜明けとともに男たちはかつての戦いへと戻り、ダルダニア勢（トロイア勢）とダナオイ（ギリシア勢）の指導者たちは戦いに向けて気力を新たにする。四方から投槍が飛び交い、鉄と鉄とが打ち鳴らされ、両軍から密集した戦列が押し寄せ、汗が血と混じり合って流れる。ついに「ダナオイの王」と呼ばれるアガメムノンが、煮えたぎる怒りに駆られ、アンティポス、ペイサンドロス、そしてペイサンドロスの兄弟ヒッポロコスを討ち倒し、戦渦へと突進する。彼は次に剣をもってイピダマスに襲いかかる。イピダマスの兄弟が投槍でアガメムノンの右腕を突くが、その痛みは彼をいっそう獰猛にする。傷を負いながらも、彼は逃走する襲撃者たる「アンテノルの子」を追跡し、復讐を果たす。

次いでヘクトルが激しい怒りに駆られて戦いに加わる。プリアモスの子ゆえに「プリアミデス」と呼ばれる彼は、打ちひしがれたギリシア勢を四方へと駆り立てる。パリスもまた敵の部隊を討ち倒し続ける。本巻は、パリスが弓を引き絞り、エウリュピュロスの太腿を傷つけ、ギリシア勢をトロイア軍の新たな攻勢のもとに残すところで締めくくられる。
