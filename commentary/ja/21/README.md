トロイアの残された安全の望みすべてをその一身に背負う唯一の男ヘクトルは、死の恐怖にも父の祈りにも引き止められることなく、強大なアキレウスを迎え撃ち戦うために進み出る。天の武具をまとったアキレウスを遠くから見つめるとき、トリトニア・パラスが突如として彼の目の前に現れる。恐怖に駆られたヘクトルは、門が閉ざされた祖国の城壁の周囲を逃げ走り、アキレウスが彼を追撃する。

ヘクトルはトロイアの最後の希望として、また不運な者として描かれる。アキレウスは「強大なる者」、またネレウスの娘である海のニュンペー（ネーレーイス）テティスを母に持つことにちなんで「ネレウスの裔なる英雄」と呼ばれる。ヘクトルの前に現れる女神は「トリトニア・パラス」、すなわちミネルウァ（アテナ）と名指される。この追撃は、ひとりが追いもうひとりが逃げるものの、その必死の努力そのものが歩みを遅らせているように見える夢に例えられる。この巻は、四方からの恐怖が彼らの怒りを掻き立てる中、休息も決着もなく追撃がなおも続くところで幕を閉じる。
