ウェヌスと、プリュギアの民の守護神アポロンは、恐るべき右手で獰猛な戦いを煽るアキレウス（アエアキデスと呼ばれる）を圧倒すべく、ダナオイに向かってクサントスの波を湧き立たせる。河はそのすべての水を溢れさせ、巨大な渦となって真っ逆さまに押し寄せ、激流の波で彼を阻んでその歩みを鈍らせる。アキレウスは全身で猛る水と戦い、逆巻く激流を突破して肩と広い胸で波を押し返す。深慮あるユノーは遠くから、彼が押し寄せる水に屈しかけたとき火をもって彼を支え、神々の聖なる力は互いに争い合う。

次いでアキレウスは、トロイア勢（プリュギアの部隊と呼ばれる）への猛攻を再開する。猛々しきアエアキデスは、戦への情熱を新たにして夥しい殺戮をもって彼らを追い立て、その必死の戦列を大混乱に陥れる。いかなる力も彼を動かすことはできず、その獰猛な心は戦いに倦むことがない。成功が彼の力を増すばかりである。この巻は、震える恐怖に襲われもはや安全の尽きかけたトロイア兵たちが、城壁の内側へと逃げ込み、閂を差し込んで堅く門を閉ざし、アキレウスを城外に残すところで幕を閉じる。
